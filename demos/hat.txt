hat.py - ten-gallon-hat / sombrero wireframe demo

Run:
  python /hat.py [wait_ms] [frames] [hold_ms]

Arguments:
  wait_ms   Delay after each rendered wire row in milliseconds. Default: 0.
  frames    Number of frames to draw. Default: 1.
  hold_ms   Time to keep the final image on screen. Default: 60000.
            Use -1 to hold until Ctrl-C or q.

Controls:
  Ctrl-C or q stops the demo.

Notes:
  This draws the classic retro-computing "hat" surface as a wireframe using
  gfx.line(). The display is presented after each wire row, so the surface
  visibly builds from back to front. With frames greater than 1, the surface
  phase changes slightly.

Examples:
  python /hat.py
  python /hat.py 20 10
  python /hat.py 5 1 -1
